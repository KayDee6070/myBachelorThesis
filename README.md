# Delineation of Watershed and Estimation of Discharge — River Tapi Sub-Basin

B.E. Civil Engineering final-year project, Savitribai Phule Pune University
(Sandip Institute of Engineering and Management, Nashik), academic year 2022–23.

The project delineates the watershed of the Tapi river sub-basin from digital elevation
data and estimates discharge at gauge-and-discharge (GD) sites, using open-source GIS
tooling end to end.

## What it covers

- **Watershed delineation in QGIS** — acquiring and reprojecting DEM tiles, running the
  fill / flow-direction / flow-accumulation chain, and deriving stream networks and basin
  boundaries into a final thematic model.
- **Discharge estimation** at GD sites across the Tapi basin, with QGIS-derived values
  compared against the observed records for those sites.
- **Thematic mapping** — location maps, reprojected DEM, basin model and discharge maps
  produced as report-ready sheets.

## Repository contents

- [`bachelor'sThesis.pdf`](bachelor'sThesis.pdf) — the full project report: introduction
  and literature review, stepwise QGIS methodology, results at each GD site, and conclusions.

## Tools

QGIS · DEM processing · watershed and stream-network delineation · hydrological analysis
